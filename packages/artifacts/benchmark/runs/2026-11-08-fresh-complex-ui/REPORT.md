## Post-trial library repairs

The fresh long-title table exposed a CSS cascade defect: the table's `padding:8px`
overrode the select arrow gutter. Measured text-to-arrow clearance was negative.
The fixed padding reserves the gutter explicitly. The standard `check.mjs` now
measures option text, clipping bounds and arrow clearance after fonts load, so the
problem is detected automatically. `gutter-before` demonstrates the checker finding
the original collision; `posttrial-matrix` records 36 clean cases after repacking.
The shared contract suite also injects the bad geometry and verifies detection.

The unavailable decorative-icon failure led to `icons.url(id,{optional:true})`,
which returns `undefined` for missing assets and leaves the service label intact.
The architecture recipe uses this guard. Strict lookups still report mistakes.
Monochrome Flow icons also refresh with themes while brand artwork is preserved.
These changes were made after the frozen trial and are not counted as fresh-agent
first-pass successes. The bundled catalog still has no official KMS asset.

Nine shared composition check groups pass, including missing-icon safety, theme
updates, measured cards, retained cameras/tabs/table state, media rail cleanup,
keyboard navigation and control geometry. The updated architecture recipe passes
all 12 theme/viewport combinations. The package's 41 checks, repository lint and
type checks, color check and skill validation pass.

The final three examples use the unchanged author sources with separately labeled

This trial supports autonomous composition from the curated patterns and automated
